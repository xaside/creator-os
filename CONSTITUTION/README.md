# CONSTITUTION

This directory holds the highest-authority governing document for CreatorOS.

The constitution defines the rules by which all other architectural decisions — RFCs, ADRs, and vision documents — are made, evaluated, and, if necessary, overridden. It changes rarely and only through explicit, deliberate process.

## Contents

- [`CONSTITUTION.md`](CONSTITUTION.md) — the governing rules of the project.

## Authority

In case of conflict between documents in this repository, the constitution takes precedence over everything else, including `ADR/`, `RFC/`, and `VISION/`.

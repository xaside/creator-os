# VISION

This directory holds the shared context for CreatorOS: what it is for, who it serves, where it is headed, and the vocabulary used to talk about it consistently.

Vision documents inform architecture but do not constitute it — they carry less authority than [`CONSTITUTION/`](../CONSTITUTION/README.md) and [`ADR/`](../ADR/README.md).

## Contents

- [`Mission.md`](Mission.md) — why CreatorOS exists.
- [`Product.md`](Product.md) — what CreatorOS is, at a product level.
- [`Roadmap.md`](Roadmap.md) — where CreatorOS is headed, and in what order.
- [`Terminology.md`](Terminology.md) — shared vocabulary used across all documents in this repository.
